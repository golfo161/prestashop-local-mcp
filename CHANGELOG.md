# Changelog

All notable changes to this distribution will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed
- Project documentation now presents `golfo161/prestashop-local-mcp` as the main distribution.
- Removed the legacy `prestashop-mcp` console script alias from package metadata.
- Runtime dependencies now exclude unused `requests`.
- Development test dependencies are now exposed through the `dev` optional extra.
- Startup logs now use plain ASCII messages and the `prestashop-local-mcp` server name.
- CLI next-step hints now use `python -m prestashop_mcp.cli ...` commands for better Windows compatibility.
- Internal package descriptions were simplified to remove inherited marketing wording.

### Removed
- Removed local `start.txt` helper with machine-specific paths.
- Removed inherited manual test scripts that could touch a live PrestaShop store.
- Removed inherited `tests/README.md` with outdated commands and encoding issues.

## [3.1.0] - 2026-08-14

### Added
- Windows assisted installer that lets users choose the local installation folder.
- Per-user secure `.env` storage under the OS user configuration directory.
- Assisted setup wizard for PrestaShop credentials and client configuration.
- Automatic Codex configuration installer.
- Automatic Claude Desktop configuration installer.
- Local helper files generated by the Windows installer:
  - `README-INSTALACION.txt`
  - `start-mcp.bat`
  - `setup-mcp.bat`
  - `update-mcp.bat`
  - `uninstall-mcp.bat`
- `get_products_by_category` for categories where products are associated but not set as default category.

### Changed
- PrestaShop authentication uses the `ws_key` query parameter for hosts that do not forward the `Authorization` header.
- README documents the GitHub-generated `main.zip` installation flow and where `pip` installs package files.
- README distinguishes assisted `.bat` workflows from manual `py -m prestashop_mcp.cli ...` commands.

### Fixed
- Normalized PrestaShop list responses returned as direct arrays.
- Category name matching is accent-insensitive and case-insensitive as a fallback.
